# Region Time Counter Mini

[English](README.md) · **Русский**

Небольшое плавающее окно, отображающее суммарную длительность всех регионов проекта в формате `HH:MM:SS`. Перекрывающиеся регионы объединяются, поэтому общие участки времени не учитываются дважды.

Зависимостей нет. Не требуются SWS или js_ReaScriptAPI.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**. Найдите **Region Time Counter Mini** в **Extensions → ReaPack → Browse packages**, установите пакет и выполните синхронизацию.

### Вручную

1. В REAPER откройте **Actions → Show action list…**.
2. Выберите **New action → Load ReaScript…**.
3. Укажите файл `Region_Time_Counter_Mini.lua`.
4. При необходимости назначьте сочетание клавиш или добавьте действие на панель инструментов.

## Возможности

- Подсчёт общей длительности объединения всех регионов.
- Корректный учёт перекрывающихся регионов без повторного суммирования времени.
- Отображение в формате `HH:MM:SS`.
- Фиксированная ширина окна без скачков размеров при изменении числа.
- Автоматическое обновление результата, пока окно открыто.
- Закрытие кнопкой окна или клавишей `Esc`.

## Примечания

Системный заголовок окна намеренно оставлен пустым, чтобы избежать ограничений минимальной ширины окон на macOS. Название отображается внутри пользовательского интерфейса.
