# Region Time Counter Mini

[English](README.md) · **Русский**

Отображает суммарную длительность объединения всех регионов проекта без повторного учёта пересечений.

## Работа скрипта

- Складывает длительности всех регионов с учётом перекрытий: пересекающиеся интервалы объединяются.
- Выводит результат в формате `HH:MM:SS`.
- Обновляет результат во время работы, если включено автоматическое обновление.
- Закрывает окно по клавише **Esc** или стандартной кнопке закрытия.
- SWS и js_ReaScriptAPI не требуются.

Пустой системный заголовок окна используется намеренно, чтобы избежать ограничения минимальной ширины на macOS.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**, найдите **Region Time Counter Mini** в **Browse packages**, установите и синхронизируйте пакет.

### Вручную

1. Скопируйте `Region_Time_Counter_Mini.lua` в папку `Scripts` ресурсов REAPER.
2. Откройте **Actions → Show action list**, выберите **New action → Load ReaScript** и укажите файл.
3. Назначьте сочетание клавиш или кнопку на панели, если требуется.

При ручном обновлении сохраняйте путь и имя файла, иначе потребуется перерегистрировать действие.
